B Code — Privacy Policy

Last updated: August 29, 2026

B Code ("we", "our", "the app") is a mobile code editor for Android. This privacy policy explains what data the app accesses, how it is used, and your rights regarding that data.

Data We Collect

We do not collect any personal data. The app does not require account creation, does not track your location, and does not sell any information to third parties.

Crash Reports

B Code uses Firebase Crashlytics to collect anonymous crash reports when the app encounters an error. These reports may include:

  • Device model and manufacturer
  • Android version and SDK level
  • App version
  • Stack traces (code execution paths that led to the crash)

Crash reports are used solely to identify and fix bugs. They are stored on Firebase's servers and are not shared with third parties. You can opt out of crash reporting in the app's Settings.

Code You Write

All code files you create, edit, or run in B Code are stored locally on your device. Your code is never uploaded to our servers. If you connect to GitHub, your code is handled according to GitHub's privacy policy.

Internet Access

B Code uses internet access only for:

  • GitHub integration (authentication, clone, push, pull)
  • Downloading language runtimes (Termux packages)
  • Crash reporting (Firebase Crashlytics)
  • Live server preview (local network only)

Third-Party Services

  • Firebase Crashlytics — anonymous crash reporting. Firebase Privacy
  • GitHub API — only when you explicitly connect your GitHub account.

Children's Privacy

B Code does not knowingly collect data from children under 13. The app is not directed at children.

Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected in the "Last updated" date above.

Contact

If you have questions about this privacy policy, please open an issue at https://github.com/bcode-editor/bcode/issues.
