B Code — Privacy Policy

Last updated: October 20, 2026

B Code ("we", "our", "the app") is a mobile code editor for Android. This privacy policy explains what data the app accesses, how it is used, and your rights regarding that data.

Data We Collect

We do not collect any personal data. The app does not require account creation, does not track your location, does not contain analytics or advertising SDKs, and does not sell any information to third parties.

Crash Reports

B Code has no crash-reporting service and no server to send data to. Crash information is written to a private file on your device.

  • If you choose Settings → Report a Bug, a draft email is prepared for you with the crash log and, if you attach them, screenshots. Nobody else sees it unless you press send in your own email app.
  • Crash logs are scrubbed of access tokens and API secrets before being written.
  • You can disable bug-report preparation in Settings, and clear the log at any time.

Code You Write

All code files you create, edit, or run in B Code are stored in app-private storage on your device. The app asks for no storage permission and does not read shared storage. Your code is never uploaded to our servers (there are none). If you connect to GitHub, your code travels only to GitHub, under GitHub's privacy policy.

Internet Access

B Code uses internet access only for:

  • GitHub integration — authentication, clone, push, pull, and browsing your own repositories. Only after you explicitly connect your account. Traffic is certificate-pinned HTTPS.
  • Language runtime downloads — only when you choose to install a runtime. Every package is verified against the published SHA-256 index before installation.
  • Preview and live-reload server — a local server on your own device (localhost only). It never sends data over the network.

Third-Party Services

  • GitHub API — only when you explicitly connect your GitHub account. Disconnecting (Settings → Sign out) deletes the stored token.
  • Termux — optional. Only if you install Termux yourself and grant it permission.

Children's Privacy

B Code does not knowingly collect data from children under 13. The app is not directed at children.

Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected in the "Last updated" date above.
